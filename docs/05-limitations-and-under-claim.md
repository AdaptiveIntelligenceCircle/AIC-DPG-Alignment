# 06 – Limitations and Under-claim

## Explicit limitations

- AIC has submitted materials related to DPGA review. This does not constitute recognition or certification.
- This repository is documentation only. It does not make AIC a Digital Public Good.
- Many core components (especially Parallel TestNet Phase 0) are still under active development.
- No formal impact evaluation has been conducted.
- Translation and adaptation layers (NPO/NGO) are early-stage.

## Under-claim rule

All documents in this repository must:

- Prefer weaker, more accurate statements over stronger, more impressive ones
- Clearly separate intent from current realization
- Avoid language that could be read as official endorsement, readiness, or guaranteed outcomes

If a sentence can be read as over-claiming, it should be revised.
