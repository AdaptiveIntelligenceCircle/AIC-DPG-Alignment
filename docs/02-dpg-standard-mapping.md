# 02 – Mapping to Common DPG-Related Expectations

**Tone:** Under-claim. This is a directional mapping, not a compliance matrix.

| Common DPG-related expectation          | AIC approach / relevant principle              | Current maturity notes                  |
|-----------------------------------------|------------------------------------------------|-----------------------------------------|
| Open source / open materials            | Public repositories under GPL-3.0 and related licenses | Active                                |
| Do no harm by design                    | Explicit design constraint + fail-closed preference | Documented, implementation ongoing   |
| Relevance to public / community purposes| Focus on independent, non-captured coordination infrastructure | Conceptual + early adaptation layers |
| Privacy and data responsibility         | Human Meaning + careful data handling posture  | Principle-level                       |
| Sustainability of the project           | Zero-donation spirit + long-term stewardship orientation | Structural intent                     |
| Clear ownership and governance          | AIC Foundation structure + public decision orientation | Evolving                              |
| Avoidance of vendor lock-in / capture   | Third Path + Non-Capture                       | Core design goal                      |

**Important:**  
Meeting a conceptual expectation in documentation does not equal full practical realization. Parallel TestNet and related work remain the primary places where these ideas are tested.
